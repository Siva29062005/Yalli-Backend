# Yalli — Canva design prompts

Copy-paste prompts for recreating / polishing the Yalli storefront and admin portal visuals
in Canva. Each prompt is written so the output stays faithful to **what the backend actually
does** — no fake buttons, no dead-end screens.

## Brand kit (paste this at the top of every prompt)

> Brand: "Yalli" — a modern Indian home & lifestyle e-commerce store.
> Colors: primary green #116644 (headers, CTAs), deep ink green #113322 (text, admin sidebar),
> accent saffron #FF9900 (sale prices, highlight CTA), light mint #EEFFEE and off-white #FFFFFE
> (surfaces), neutral #8A958E for muted text.
> Fonts: Poppins for headings/display, Inter for body/UI text.
> Shape language: rounded corners (16–20px), soft card shadows, pill-shaped chips/buttons.
> Tone: clean, trustworthy, premium-but-warm. Prices always in ₹ (Indian Rupees, GST inclusive).
> Categories in the main nav (exactly these 8): All, Electronics and Gadgets, Home Accessories,
> Kitchen and Dining, Combo, Outdoor and Travel, Health and Wellness, Yalli Products.

## Backend-faithfulness notes (things not to fake in the designs)

- **Prices** are shown in ₹ and are GST-inclusive; sale prices come from scheduled variant
  sale windows — a SALE chip is only valid when a sale price exists.
- **Payments** are exclusively Razorpay (UPI/cards/netbanking). There is no COD — do not draw
  a "Cash on delivery" option in checkout.
- **Orders** pass through: `CREATED → INVENTORY_RESERVED → PAID → PROCESSING → SHIPPED →
  DELIVERED`, with `CANCELLED`/`RETURN_*` branches — use exactly these status words on pills.
- **Payment window**: unpaid orders expire — the countdown chip on the order page is real
  (payment status is polled).
- **2FA**: staff accounts use TOTP + recovery codes; the 6-box code card and
  "fresh step-up within 30 minutes" lock note on admin pages are real behavior.
- **Returns**: a 7-day replacement window from delivery; refund reason list is fixed
  (Damaged/Defective, Wrong item, Size or fit, Changed my mind, Other).
- **Shipping methods and rates** are admin-configured — show at most 2–3 methods, never a
  generic courier list.
- **Roles** in the admin are exactly: SUPER_ADMIN, ADMIN, MANAGER, CUSTOMER_SUPPORT,
  CUSTOMER — don't invent others.
- **Guest carts**: a visitor can add to cart without an account; cart merges after login —
  there is no "cart requires login" wall in the design.
- **The 8 categories** are fixed — any mega-menu, footer, or category-tile design must use
  exactly: All, Electronics and Gadgets, Home Accessories, Kitchen and Dining, Combo,
  Outdoor and Travel, Health and Wellness, Yalli Products.
